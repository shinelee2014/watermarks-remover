🛡️ 四大技术防御矩阵

A

Layer A: 隐式 Unicode 确定性净化

精准识别并剥离零宽字符（ZWSP U+200B、ZWNJ U+200C）、Bidi 覆写控制符、Unicode 标签字符（U+E0001..7F）、变体选择符（VS）以及私有区（PUA），同时针对 Emoji 连字符与复合正字法做非破坏性保护。

B

Layer B: 统计采样水印对抗 (Token Bias Rewrite)

针对绿红列表（Kirchenbauer）与 SynthID-Text 采样偏置，通过非源头大模型进行句法结构、功能词与连词的深度洗牌重写，并利用 Bigram Jaccard 词汇发散度算法打分选优。

M

媒体与容器元数据物理剥离

纯二进制解析 PNG/JPEG/WebP/SVG 的 C2PA JUMBF Manifest、EXIF、Adobe XMP、ICC 配置文件；对 DOCX/ODT 进行流式解压预算清洗，对 PDF 配合 qpdf --linearize 杜绝增量修改残留。

P

双模运行与绝对隐私

默认使用 100% 浏览器客户端引擎（WebAssembly/JavaScript），所有计算均在您的设备内完成；可无缝接入本地 Python 服务（http://127.0.0.1:8765）扩展专业重构后端。
